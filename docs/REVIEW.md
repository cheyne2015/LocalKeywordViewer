# 2.0 审查记录

比较基线：`v1.4.1`。检查依据为 `CONTRIBUTING.md` 和 `docs/SPEC.md`，采用独立的 Standards / Spec 两轴审查。

## Standards

- 设置导出直接覆盖备份：已改为同目录临时文件加原子替换。
- 切库期间旧异步任务仍可能写入统计摘要：等待返回后增加版本校验。
- 切库未更新 Everything 程序偏好：切库重新发现程序，显式选择的路径优先。

## Spec

- 允许的最长资料库名称不能重新导入：导入验证与新增上限统一，超长时不追加后缀，并加入往返测试。
- 新流程文档不完整：README 增补资料库、格式统计、迁移、导入导出和公开发布说明。

## 验证

核心检查覆盖缓存、分词、组合搜索、格式组内去重、旧索引升级、多资料库隔离、最后选中库、改名、移除保留源文件、无路径导出／导入及单实例通知。

WPF 检查使用虚构数据，覆盖控件接线、屏蔽恢复、排序字数、默认瀑布流连续加载、资料库切换、格式文件数及重置筛选。发布前另做正式窗口和已部署文件校验。

目录符号链接创建受 Windows 测试账户权限影响；扫描器拒绝链接的逻辑已有检查。Everything 的原生文件打开、移动、删除功能不属于本面板实现。
