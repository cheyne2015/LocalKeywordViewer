## 高频关键词面板 2.0.0

新增多资料库及文件格式筛选，保留现有 Everything 作为文件结果窗口。

- 一库一个目录，独立缓存、屏蔽词、规则与筛选偏好；旧设置及缓存自动迁移并保留原副本。
- 格式仅列出现有类别、扩展名；选定格式后同步重新统计组内去重词频，并向 Everything 传递相同格式条件。
- 固定展示已选关键词，支持逐项取消与重置筛选。
- 新增单实例唤回、版本显示、设置导入／导出及离线缓存状态。
- 默认导出省略本机路径，索引不导出。分享前仍应检查资料库名称与屏蔽词。

Windows x64 自包含包无需单独安装 .NET；解压完整目录后运行 KeywordViewer.exe。Everything 需自行安装，本包不含其程序、数据库或设置。原启动器如要求管理员确认，首次仍需用户处理。

检查：核心与隔离 WPF 样本测试、独立双轴代码审查、Windows 自动检查、正式程序运行及发布文件校验。公开文件与 Git 历史经过隐私检查，不含本机索引、真实文件清单、屏蔽词、调试符号或验收截图。
