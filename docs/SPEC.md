# 2.0 交付范围

1. 每个资料库对应一个根目录；新增、切换、改名、修改目录和移除资料库。移除只处理应用数据，原文件不变。
2. 每库独立缓存、屏蔽词、关键词规则和筛选偏好；记住当前库。旧版本缓存及设置自动迁移，保留旧副本。
3. 格式筛选只显示实际存在的类别及扩展名。选择格式后按匹配文件重新计算一级资料组去重词频，匹配数和 Everything 的格式条件一致。
4. 关键词按频率、名称、字数及方向排序；字数只显示当前候选中的真实字数。默认虚拟化瀑布流，整页无选中框；Ctrl 多选和 × 屏蔽保留。
5. 已选词固定展示，可单独取消；重置筛选清空文字、格式、字数和选词，不清空屏蔽偏好。
6. 单实例运行，再次启动激活原窗口。设置可导入导出；默认导出省略目录及程序路径，索引不导出；导入不覆盖现有库。
7. 显示版本、扫描更新时间、进度、跳过项及离线状态。后台刷新可取消，失败及取消保留上次完整索引；离线可浏览缓存。
8. 保留已有 Everything，自动启动及复用现有进程，不修改其设置或系统权限。程序及数据库不随包分发。
9. 公开仓库只有源码、开源资源、文档及虚构测试。索引、真实文件名/路径、屏蔽词、私有验收记录、配置及凭证均不提交。
10. 完成检查、窗口验收及包校验后发布 Windows x64 自包含 Release，提供校验值。旧版正式目录用户数据保持可恢复。

## 2.1 逐层检索

1. 普通点击当前层关键词，按全部已进入条件 AND 匹配文件名和相对文件夹名，在匹配文件内重新计算一级资料组去重词频。只读取名称索引，不扩大到匹配组中的其他文件，不受首页前 100 个词限制。
2. 不限层数；顶部显示路径，可返回任意层并清除后续条件。已进入词不再作为候选；没有更多词时提示并保留文件结果。
3. 点击词组和进入下一层均不启动 Everything；仅“在 Everything 查看”发送当前组合、暂存词、附加文字和格式条件。
4. Ctrl 点击或暂存多选勾选后只增减当前层待进入词，排行暂不变化。“进入下一层”批量提交同层条件，全部同时匹配。
5. 首页保留原门槛，下级门槛默认 2 组，可调整并独立按库保存；屏蔽、词长、语言规则继续生效。
   主动搜索时放宽频率至 1 组，其他规则继续生效；清空搜索恢复当前层原门槛。扫描、格式筛选、下钻及旧缓存升级均保留单组统计，保证主动搜索能找到这些词。
6. 进入或返回一层清空关键词搜索框，保留格式、字数、排序及屏蔽。无匹配的当前字数保留并明确标记，不悄悄放宽条件。格式改变后重新统计当前范围。
7. 清空选择及重置筛选清除所有层级和暂存词；切库时不带入旧库的路径、后台结果和暂存词。保留虚拟化、分页与后台取消/结果版本隔离。

## 2.2 英文、数字及字母数字关键词

1. 从文件名和相对文件夹名提取独立年份、保留前导零的数字、英文和字母数字组合，例如 2026、high、01、a1。复合名称保留整词并按连接符拆出组成词，继续忽略完整日期、网址、哈希、扩展名及停用词。
2. 保留仅中文选项；关闭后可显示英文与混合标签，并可单独开关纯数字，按最短～最长位数设置，默认 2～6 位，范围需满足 2 ≤ 最短 ≤ 最长 ≤ 15。资料组、长度、格式、屏蔽和逐层检索继续一致生效。
3. 对已存在但采用旧分词规则的缓存，按名称索引版本后台重建每文件词集及一级资料组频率，无需读取实际文件或正文；升级不改变文件记录、原目录或文件属性，升级结果按原缓存路径保存。
4. 测试覆盖实际示例、完整日期/网址/哈希噪声、数字长度上下限/开关、同组去重、已填充旧缓存升级，以及窗口规则保存、查词与下钻。
